Neutral — color untouched

Color is untouched unless you ask. Every image is cut straight out of your original file at full resolution. No sharpening, no background removed, nothing cloned. With warmth at neutral the pixels are never even read back — the file is the crop, and a rotation if you asked for one.

Quarter turns are free. The ↺ and ↻ buttons move whole pixels, so the coin is untouched. The slider gets you close and −1° / +1° land it; any angle off the square means the pixels have to be redrawn, and the corners are filled in with the color of your scanner bed taken from the edge of the scan. The angle turns gold to tell you which coins that happened to.

Warmth touches the coin, not the paper. It moves red up and blue down together — a white balance, the thing a photographer does with a gray card, not a color grade. The background stays exactly as scanned, so a white bed stays white instead of going cream. Better still, set the warmth in your scanner software and leave this at neutral, so the file is right before it is ever saved.

If it misses coins or finds things that are not coins
  • Leave a gap between coins. Touching coins are read as one.
  • Hover the rotate controls to bring up an alignment cross. The coin turns under it, so line the date or the legend up against it.
  • Every zip includes a small manifest.csv listing each file's ID, side, angle and size — nothing you need to read, but it is what lets the rest of the system use these images without asking you questions.
  • Type the Inventory ID under a coin and the file is named for it — BWC-2026-0000074-front.png. Scan the fronts, then the backs in the same order, and the pairs name themselves.
  • Raise edge sensitivity for coins close in tone to the background.
  • Any background works — white, black, a colored card. It learns the background from the edge of the scan.
  • Close the lid, or lay a plain card over the coins. A busy background gives it more to find.
